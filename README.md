#النخبة للشحن

تطبيق ويب عربي لإدارة شركة شحن، يعمل كـ PWA ويمكن تثبيته على الموبايل من المتصفح.

## الموجود في النسخة الحالية

- دخول بأربع صلاحيات: إدارة، تاجر، مندوب، عميل.
- لوحة شحنات للتاجر والإدارة.
- مهام للمندوب مع زر اتصال وتحديث حالة التسليم.
- تتبع شحنة للعميل.
- حسابات وتحصيلات ورسوم شحن.
- واجهة RTL متجاوبة للموبايل والكمبيوتر.
- Manifest وService Worker للتثبيت كتطبيق.

## حسابات التجربة

كلمة المرور لكل الحسابات: `123456`

- الإدارة: `01000000000`
- التاجر: `01000000001`
- المندوب: `01000000002`
- العميل: `01000000003`

## تشغيل محلي

```bash
npm start
```

ثم افتح:

```text
http://127.0.0.1:4173
```

## الرفع

هذه نسخة Static، لذلك تقدر ترفع الملفات مباشرة على:

- Netlify: اسحب مجلد المشروع على Netlify Drop.
- Vercel: أنشئ مشروع جديد واختر هذا المجلد، ولا تحتاج Build Command.
- GitHub Pages: ارفع الملفات إلى repository ثم فعّل Pages من Settings.
- أي استضافة عادية: ارفع `index.html` و`styles.css` و`app.js` وباقي الملفات كما هي.

## الخطوة الاحترافية التالية

لتحويلها لنظام إنتاج كامل:

- Backend: Node.js + Express أو NestJS.
- Database: PostgreSQL أو Supabase.
- Auth: تسجيل دخول حقيقي بصلاحيات.
- Storage: رفع صور إيصالات وبوالص شحن.
- Notifications: واتساب أو SMS عند تحديث حالة الشحنة.
- Payments: محفظة/تحويلات للتجار والمندوبين.
